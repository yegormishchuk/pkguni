# Лабораторная работа №2 — чтение информации из графических файлов

Веб-приложение читает из файлов JPG, GIF, TIFF, BMP, PNG и PCX размер, разрешение (DPI), глубину цвета,
сжатие и дополнительные данные (палитры, матрицы квантования JPEG, EXIF, кадры GIF, теги TIFF).
Выполнено с дополнением для группы 10А: ручной побайтовый разбор без сторонних библиотек, ленивое чтение
заголовков, Web Workers с прогресс-баром, обнаружение повреждённых файлов и подменённых расширений.

## Запуск

ES-модули и Web Worker'ы не работают при открытии `index.html` напрямую, нужен любой статический сервер:

```
npx serve .
# или
python -m http.server
```

Число потоков можно задать параметром адреса: `index.html?threads=4`.

## Тесты

```
npm test
```

Эталонные изображения в `tests/fixtures` создаются скриптом `tests/fixtures/make_fixtures.py` (нужен Pillow;
он используется только для генерации тестовых файлов, приложение его не использует).

## Структура

- `js/model` — разбор форматов (`formats/*.js`), ленивый доступ к байтам (`byteSource.js`), определение формата (`analyze.js`)
- `js/worker`, `js/services` — рабочий поток и пул потоков
- `js/viewmodel` — состояние, фильтры, сортировка, прогресс, CSV
- `js/view`, `index.html`, `style.css` — интерфейс
