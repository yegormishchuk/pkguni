Методы, формулы и сравнение результатов

Все методы работают с яркостью Y = 0,299R + 0,587G + 0,114B. Прозрачность накладывается на белый фон. Пиксель становится белым, если Y > T, иначе — чёрным.

МетодПравилоЧто проверять
НиблэкT = m + kσТонкие малоконтрастные линии; на текстурном фоне может сохранять шум.
БернсенT = (min + max) / 2Контрастные детали. При max − min < C всё окно классифицируется по середине диапазона относительно 128.
СауволаT = m [1 + k(σ/R − 1)]Текст на неоднородном светлом фоне; адаптация к локальному разбросу яркости.
БрэдлиT = m(1 − t/100)Быстрый адаптивный порог по локальному среднему.
Медиана / минимум / максимумСредний / первый / последний элемент упорядоченного окнаМедиана убирает импульсы; минимум расширяет тёмные области, максимум — светлые.

m и σ вычисляются за O(1) на окно по интегральным изображениям суммы и суммы квадратов. Для ранговых фильтров и Бернсена используется скользящая гистограмма. Потоки обрабатывают полосы с перекрытием на радиус окна: швы отсутствуют.

Края: Clamp повторяет крайний пиксель; Reflect зеркалит без повторения крайнего пикселя. Исходник не изменяется. Параметры применяются кнопкой, а не автоматически.
