# Лабораторные работы по компьютерной графике

Общий репозиторий лабораторных работ Мищука Егора. Каждая работа находится в отдельной папке вместе с исходным кодом, тестами и отчётом.

| Работа | Тема | Папка |
| --- | --- | --- |
| №1 | Цветовые модели RGB, XYZ, LAB и CMYK, вариант 3 | [lab1](lab1/) |
| №2 | Чтение метаданных графических файлов JPG, GIF, TIFF, BMP, PNG и PCX | [lab2](lab2/) |
| №3 | Локальная и адаптивная пороговая обработка, порядковые фильтры; вариант 15 | [lab3](lab3/) |

## Запуск

Из корня репозитория запустите статический HTTP-сервер, например:

```sh
python -m http.server 8000
```

Откройте нужную работу:

- Лабораторная №1: <http://localhost:8000/lab1/>
- Лабораторная №2: <http://localhost:8000/lab2/>
- Лабораторная №3: <http://localhost:8000/lab3/>

Для второй работы требуется HTTP-сервер: ES-модули и Web Workers не работают при открытии HTML как локального файла. Подробности — в [инструкции к лабораторной №2](lab2/README.md).

## Тесты

Требуется Node.js 20 или новее. Установка npm-зависимостей не нужна.

```sh
npm test
```

Отдельные работы:

```sh
npm run test:lab1
npm run test:lab2
npm run test:lab3
```

## Добавление следующих работ

Создавайте папки `lab4/`, `lab5/` и далее внутри этого репозитория, без вложенного `git init`. Добавляйте работу в таблицу выше и, если есть автоматические тесты, в скрипты корневого `package.json`.
