# Лабораторная работа №1 — цветовые модели

Вариант 3. Веб-приложение для преобразования цветов между RGB, XYZ, LAB и CMYK. Поддерживает выбор источника освещения, адаптацию белой точки Брэдфорда, обработку выхода за цветовой охват и настройку цветоделения CMYK.

## Запуск

Из корня общего репозитория:

```sh
python -m http.server 8000
```

Откройте <http://localhost:8000/lab1/>.

## Тесты

Из этой папки выполните `npm test`, либо из корня репозитория — `npm run test:lab1`.

## Структура

- `js/model` — расчёты и преобразования цветов.
- `js/viewmodel` — состояние приложения и синхронизация моделей.
- `js/view`, `index.html`, `style.css` — интерфейс.
- `tests` — автоматические тесты.
- `Отчёт_Лабораторная_1_Мищук_Егор.docx` — отчёт.
